# SLIDE v4 C++ API

This reference documents the public C++ types in the v4 development core and
the retained v3 façade. Start new integrations with the `slide::core`
namespace; the v3 surface remains available through v4.x for migration.

The [SLIDE user guide](https://battery-intelligence-lab.github.io/SLIDE/)
contains installation instructions, executable C++/Python/MATLAB quickstarts,
the optional-dependency matrix, declared PyBaMM compatibility gaps, and
contributor guides for new model families and ageing mechanisms.

The v4 API is a development preview until the `v4.0.0` release gate aligns all
package versions and publishes reproducible artifacts.
